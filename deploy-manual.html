Terminal (CMD)
# افتح الشاشة السوداء داخل مجلد المشروع واكتب:

git add .
git commit -m "My First ERP"
git branch -M main
# الآن اذهب لموقع GitHub.com وأنشئ New Repo وانسخ الرابط وضعه هنا:
git remote add origin https://github.com/YOUR_NAME/nexgen-erp.git
git push -u origin main
