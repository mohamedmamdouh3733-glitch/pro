
=== نظام NexGen ERP - دليل التشغيل والنشر ===

--- التشغيل المحلي (على جهازك) ---
1. تأكد من وجود Node.js.
2. افتح موجه الأوامر (CMD) في مجلد المشروع.
3. اكتب: npm install (مرة واحدة فقط).
4. اكتب: npm run dev
5. سيفتح الموقع على: http://localhost:3000

--- النشر على الإنترنت (مجاناً مدى الحياة) ---
الخطوة 1: رفع الكود على GitHub
- أنشئ حساباً على GitHub.com.
- ارفع ملفات المشروع (ماعدا مجلد node_modules).

الخطوة 2: الربط مع Vercel
- اذهب إلى Vercel.com وسجل الدخول بحساب GitHub.
- اضغط "Add New Project" واختر مشروع "nexgen-erp".
- في خانة "Environment Variables" أضف:
  * الاسم: API_KEY
  * القيمة: (مفتاح الذكاء الاصطناعي الخاص بك من Google)
- اضغط "Deploy".

مبروك! ستحصل على رابط (Domain) يعمل في أي مكان في العالم.
